# 盈亏计算验证报告

## 1. 计算口径

**已通过代码验证**

### 已实现盈亏

- 仅来自 VERIFIED + VERIFIED + `is_paper = 0` 的卖出。
- 卖出收入按成交单价 × FIFO 消耗数量。
- 成本按消耗批次剩余 cost 分摊，不使用当前市场价。
- SELL_EXPENSE 费用按批次分摊，尾差由最终批次吸收。
- 任一 UNKNOWN 成本或 UNKNOWN 费用导致正式已实现盈亏为 `null`；同时保留 `knownRealizedPnl` 作为不完整已知值，不伪装完整结果。

### 未实现盈亏

- 库存成本来自剩余 FIFO lot。
- 估值必须来自最新完整资产快照对应的最新 COMPLETED valuation。
- 提供市场参考、买单逐档清算净值、卖单逐档重置总值、卖单逐档重置净值四种独立口径。
- 数量不一致、成本未知或无估值时返回 N/A/null。
- 不把市场参考价值称为实际可变现价值。

### 绩效

- 累计买入/卖出金额只来自已验证交易。
- 总费用在未知时返回 null。
- 盈利交易比例按 sell record 聚合，避免多 lot 导致比例大于 100%。
- 平均持仓时间、单笔盈亏和 byType/byLocation/byStrategy 只使用已计算 FIFO consumption。

## 2. 修复内容

**已通过代码验证；已通过隔离测试数据验证**

- 未知费用曾可能显示为 0；已修复为 null。
- 单笔卖出跨多个 FIFO lot 时，盈利交易比例曾可能大于 1；已改为按卖出记录聚合。
- 成本精度不足导致重复小数时 PnL 偏差；已改为剩余成本分摊和单位成本高精度。
- 未实现盈亏可能混用不同快照估值；已绑定最新完整快照。
- FINAL lot 费用/成本余差不再丢失或重复。

- 0.01 ISK 费用尾差：通过。
