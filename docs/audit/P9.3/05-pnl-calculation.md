# P9.3 盈亏计算口径报告

## 已实现盈亏

`卖出收入 - 卖出对应 FIFO 成本 - 相关卖出费用`。

只有全部相关成本和费用已知时输出确定数值。任何 UNKNOWN 成本、UNKNOWN 费用或 `UNKNOWN_SOURCE` 消耗都会让总已实现盈亏返回 N/A，同时保留已知小计用于审计，不伪装完整绩效。

## 未实现盈亏

按库存估值口径独立计算：

- 市场参考价值：标注为参考价值，不称为实际可变现价值。
- 买单逐档清算净值。
- 卖单逐档重置总值。
- 卖单逐档重置净值。

`未实现盈亏 = 当前库存估值 - 剩余 FIFO 成本`。数量不匹配或成本 UNKNOWN 时返回 N/A。

## 绩效指标

输出累计已实现盈亏、当前未实现盈亏、总交易费用、累计买入/卖出、库存成本、资金占用、交易次数、盈利交易比例、平均持仓时间、单笔盈亏以及按物品/地点/策略分组的盈亏。

## 测试数据说明

当前单元测试使用明确标记的测试数据（Type ID 34，内存 SQLite），不是真实交易绩效。没有真实成交样本时不得声称真实收益已验证。
