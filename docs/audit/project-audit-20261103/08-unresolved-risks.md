## 2. 当前资产估值是旧快照

**已通过真实环境验证**

- 最新资产快照：513 items。
- 最近估值绑定：旧 483 items 快照。
- UI 已显示 `STALE` 警告，不再把旧估值当作当前库存总值。

## 3. 对账结果包含 406 个 UNKNOWN_SOURCE

**已通过真实环境验证**

最新对账绑定旧快照，406 个聚合键全部为 `UNKNOWN_SOURCE`。这是账本为 0、资产有库存时的合理历史结果，不代表 406 笔交易。

## 4. 行情新鲜度

**已通过真实环境验证**

实际页面显示行情更新约 271 分钟前，`market_orders` 虽已有 1,561,888 条数据，但新鲜度不足。系统有陈旧的可见提示，但没有在只读审计中强制刷新市场快照。

风险：依赖行情的机会、估值和 AI 分析必须继续显式展示数据时间，不能用“有数据”代替“当前数据”。
