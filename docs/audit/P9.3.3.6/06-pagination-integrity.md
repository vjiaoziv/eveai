# 06 分页完整性

## 严格规则

- paginated ESI 响应缺少 `X-Pages`：失败
- 非正数、非整数、非有限数：失败
- 超出安全整数：失败
- 收集过程中 `X-Pages` 改变：失败
- 页数超过调用预算：失败

## 提交边界

所有页和所有行先完成获取、类型校验、canonical 计算和数量聚合，之后才进行一次性数据库事务。失败不会创建 COMPLETED snapshot，不会覆盖上一份有效 mirror，也不会推进成功状态。

## 测试

P9.3.3.6 分页专项覆盖缺失、`0`、负数、非整数、无穷、NaN、安全整数溢出、收集期间变化、页预算超限及 generic adapter 失败传播。
