# Pre-P8 Audit Archive

Status: historical
Archived: 2026-11-04

This directory preserves baseline, independent-audit, defect, and implementation
records that predate the phase-scoped P8 archive. Original filenames and report
content are retained. These documents describe historical states; current
behavior must be verified against code and tests.

## Reading Order

1. Start with the baseline and highest-level findings in `TRADING_SYSTEM_AUDIT.md`, `EXISTING_CAPABILITIES.md`, and `SECOND_AUDIT_REPORT.md`.
2. Follow the defect list into the focused data, fee, portfolio, backtest, deployment, and security reviews.
3. Use `FIRST_TRADE_RECALCULATION.md` for the concrete phantom-spread incident.
4. Finish with `IMPLEMENTATION_REPORT.md`, `INSTALLATION_REPORT.md`, and `DEPLOYMENT_GUIDE.md` for the state after corrective work.
