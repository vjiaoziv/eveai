# 10 未解决风险与后续验证

## 必须保持的状态

- REAL_ACCOUNTING_READY：代码和隔离测试已达到真实会计核算准备边界。
- REAL_ACCOUNTING_OPERATIONALLY_VERIFIED：尚未达成，禁止宣称。

## 真实环境尚未验证

1. 真实角色 OAuth scope 是否包含 esi-wallet.read_character_wallet.v1，以及撤销授权后的实际错误路径。
2. 真实 ESI 钱包交易的 from_id 分页、X-Pages、空页和页面稳定性。
3. 请求期间真实跨设备活动角色切换、解绑和所有权变化。
4. 真实钱包超大批次下 30 秒租约是否会在持久化阶段过期。
5. 真实异常余额、异常资产结构和未知 location_type 的兼容性。
6. 真实人工核实、证据冲突、冲正、更正和费用补录闭环。
7. 真实经纪人费、销售税和费用归属完整后，FIFO 确定性盈亏是否满足业务验收。
8. 多用户、多角色、多实例生产部署下的长期并发表现；本轮已完成单机独立子进程的隔离租约验证，但未做生产多实例长稳测试。

## 已知工程限制

- 钱包同步没有租约续期机制。超过 30 秒的持久化会安全失败并允许后续重试，但可能降低大批次吞吐。
- real_esi_transaction_failures 已持久化，但当前只有同步状态错误文本；尚未提供独立失败列表、人工隔离或忽略确认界面。
- FIFO freshness 已覆盖 API 和主要前端组件，但未进行真实浏览器人工视觉验收。
- 构建仍有 Vite chunk 体积提示，不影响本阶段正确性，但后续可考虑代码分割。
- 本阶段未应用生产数据库迁移；部署前必须在受控环境执行迁移、备份和回滚演练。

## 继续条件

只有在真实账号、真实钱包数据、人工核实、费用完整性、FIFO 和盈亏闭环均完成受控验证后，才可以讨论 REAL_ACCOUNTING_OPERATIONALLY_VERIFIED。不得自动启动 P9.3.4/P9.4，不得自动部署。
