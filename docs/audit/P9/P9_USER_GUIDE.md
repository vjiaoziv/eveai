# P9 User Guide

## 首次使用

1. 启动 EVEAI 并登录 Web。
2. 连接 EVE 角色并授予所需只读 scope。
3. 等待市场快照完成首次同步。
4. 打开侧栏“交易工作台”。

需要的常用 scope：

- `esi-wallet.read_character_wallet.v1`
- `esi-assets.read_assets.v1`
- `esi-markets.read_character_orders.v1`

缺少 scope 时页面显示 `no_scope`，不会伪造余额或资产。

## 扫描机会

“系统设置”中配置：

- 贸易中心地点 ID、区域 ID、名称
- 两类策略
- 最低净利润、最低 ROI
- 最大资金、行情年龄、结果数
- 自动扫描开关和间隔

回到“机会中心”点击“立即扫描”。

机会卡片区分：

- 理论毛利润
- 订单簿可执行毛利润
- 费用后净利润
- 综合净利润或 UNKNOWN

跨区机会物流未知时不会显示为最终利润。

## 生成和确认方案

1. 机会中心点击“生成方案”。
2. 打开“交易方案”检查数量、价格、费用、风险、有效期。
3. 点击“人工确认”。
4. EVEAI 不会下单。

## 执行真实交易

1. 在 EVE 客户端自行买入/卖出。
2. 回到“真实交易记录”。
3. 逐笔录入每个成交；部分成交使用不同 `clientKey` 多条记录。
4. 留下真实时间、地点、费用和备注。
5. 系统自动 FIFO 重算库存和实际盈亏。

也可以点击“同步 ESI 真实交易”，通过 wallet transactions 导入并去重。

## 库存成本

对 ESI 无法推断来源的资产：

- 打开“库存管理”
- 输入 Item/Type/地点/数量
- 有真实采购成本则填写
- 不知道成本则留空，状态保持 UNKNOWN

不要用当前市场价冒充历史采购成本。

## 查看绩效

“策略绩效”只显示 REAL：

- 真实交易数
- 买入/卖出数
- 已实现净盈亏
- 已支付费用
- 未知成本数量

Paper Trading 在独立页面，不合并收益。

## AI 分析

“机会中心 → AI 解释”或“策略绩效 → 每日 AI 报告”。

AI 只解释数据库字段。看到 UNKNOWN、数据过期或物流未知时，应把它视为限制，而不是让 AI 猜测。

## 常见错误

- `尚未关联 EVE 角色`：先连接并激活角色。
- `no_scope`：重新 EVE 登录并勾选只读 scope。
- `DATA_STALE`：等待市场快照刷新后重新扫描。
- `UNKNOWN_COST`：人工确认采购成本。
- `相同 clientKey 已用于不同交易参数`：更换幂等 Key，避免重复或错误覆盖。
- `ESI 来源记录不可静默覆盖`：在同步状态或审计中说明差异，不直接改权威记录。

## 2026-11-03 新增操作

### 查看机会详情

1. 打开“机会中心”。
2. 在机会行点击“详情”。
3. 弹窗显示：买入/卖出订单簿、逐档匹配（本档成交与累计）、采购成本、销售收入、各项费用、费用后净利润、综合净利润或 UNKNOWN、风险标记、数据源、买卖快照 ID 与时间、计算版本、关联交易方案。
4. 可在弹窗内直接“生成交易方案”；仍然只是建议，不会下单。

### 管理贸易中心

1. 打开“系统设置 → 贸易中心白名单”。
2. 每个地点可修改 ID/名称，可用“启用”勾选框停用，用“删除”移除。
3. 点击“添加贸易中心”新增一行，填写地点 ID、区域 ID、名称后保存。
4. 保存时系统用当前 SDE 校验：区域必须存在；若地点是 SDE NPC 空间站，其真实区域必须与填写的区域一致。

### 指定商品扫描

1. 打开“机会中心”。
2. 在“指定 Type ID（逗号分隔，留空=自动候选）”输入一个或多个 Type ID。
3. 点击“按 Type 扫描”；留空时使用自动候选（按价差排序的高流动性商品）。

### 查看行情状态

“交易总览”顶部显示：ESI 行情状态、行情快照时间、行情数据行数、整体是否陈旧；下方“ESI 行情与贸易中心状态”表格按启用的贸易中心列出最近采集时间、年龄、新鲜度与错误。
