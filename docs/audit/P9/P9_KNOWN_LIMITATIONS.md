# P9 Known Limitations

## 数据限制

1. 公共 ESI 区域订单不等于全部市场。
2. 合约、私有/未观察建筑、未发布报价不能被当作不存在。
3. 结构地点名称可能缺失，只能显示 ID 或 UNKNOWN。
4. ESI wallet transactions 的历史窗口和字段受 CCP 接口约束。
5. 资产快照差异不能直接当作成交，当前不自动生成已实现盈亏。
6. 日均价格不能用于实时可执行利润。

## 机会限制

1. 快照在下单前可能变化；成交仍由用户在游戏内确认。
2. 跨贸易中心物流成本当前保持 UNKNOWN。
3. 综合净利润通常为 UNKNOWN，不以费用后净利润冒充最终利润。
4. 自动扫描默认关闭，避免不必要的任务负载。
5. 第一阶段只重点完善站内套利和跨贸易中心套利。

## 盈亏限制

1. 无法确认采购成本的库存盈亏为 UNKNOWN。
2. ESI fee 缺失时费用状态 UNKNOWN。
3. 资产中的既有库存若未人工建立 lot，不会被自动推断为历史买入。
4. 未实现盈亏是逐档、扣费后的估算，不是保证变现值。
5. REAL 与 PAPER 绝不合并；任何合并总收益都是错误。

## AI 限制

1. AI 不参与价格、费用、数量、盈亏或阈值计算。
2. AI 不会自动下单。
3. 模型不可用时分析接口返回 503，不影响确定性扫描和记录。
4. AI 输出必须引用 ID 和数据时间；缺失时用户应视为数据不足。

## 产品限制

1. 当前没有浏览器端 Playwright 自动化测试；关键路径由 TypeScript、构建和 API/核心测试覆盖。
2. 没有真实 EVE 登录样本时，不能声称真实资产同步已在目标账户成功运行。
3. 没有真实 Paper 运行样本，不能给出策略盈利排名。
4. P9 不得输出 `REAL_TRADING_READY`。

## 2026-11-03 补充

1. 真实 ESI 数据中，三个默认贸易中心的同地点交叉订单（买单价 > 卖单价）均为 0：这是 EVE 撮合机制的正常结果。站内套利算法与测试齐全，但真实市场通常不会留下即时站内交叉机会；本轮如实报告 0，不构造数据。
2. 跨贸易中心机会的物流成本当前仍为 UNKNOWN，综合净利润保持 UNKNOWN；费用后净利润只是“不含运输的估算”，不是最终可实现利润。
3. 本次真实 ESI 验证在隔离数据库副本执行。生产 `eveai.service` 在验证期间被外部因素频繁重启（约 15–40 秒一次），导致其行情 cron 无法完成整轮刷新；这不是 P9 代码缺陷，但会影响生产库行情新鲜度，需运维侧确认重启来源。
4. 生产库行情快照在本次会话开始时为 2026-11-02 15:50Z，属于过期数据；系统会将其机会标为 `STALE`，不会冒充新鲜行情。
