# P9.2 多口径估值方法

## 1. 估值对象

只估值最新 `COMPLETED` 快照。若快照缺失、非完整或当前集与快照头不一致，不生成可信估值。

## 2. 五个口径

### A. 市场参考价值

- 数据：该资产所在区域的本地订单簿最高卖单
- 计算：`region_top_ask_price × quantity`
- 用途：市场参考，不代表可立即变现
- 状态：无区域订单时 `NO_MARKET_DATA`

### B. 买单深度清算价值

- 数据：资产精确位置的买单
- 计算：按买单价格从高到低逐档吃单
- 输出：
  - `bid_liquidation_gross`
  - `bid_liquidation_net`
  - `fillable_quantity`
  - `unfillable_quantity`
- 费用：立即卖入买单只收销售税，不收卖单经纪人费
- 深度不足：`INSUFFICIENT_DEPTH`
- 这是订单簿可执行模型，不是已成交收入

### C. 卖单重置成本

- 数据：资产精确位置的卖单
- 计算：按卖单价格从低到高逐档买入
- 输出：
  - `ask_replacement_gross`
  - `ask_replacement_net`
  - `fillable_quantity/unfillable_quantity`
- 用途：重置同等库存的参考成本
- 不得当作资产实际价值

### D. 成本基础

- P9.2 没有可靠人工采购记录
- 永远为 `null`
- 状态：`UNKNOWN_PENDING_P9_3`
- 禁止用当前价格反推历史成本

### E. 综合展示

四个口径并排展示，禁止相加：

- 市场参考估值
- 买单深度可执行估值
- 卖单重置成本
- 历史成本 `UNKNOWN`

## 3. 费用模型

复用 P9.1.1 `FeeEngine`：

- 版本：`eveai-fee-2026-11-v1`
- 默认上下文：
  - clone：`alpha`
  - skills：`ALPHA_DEFAULT_SKILLS`
  - facility：`npc_station`
- Accounting III 销售税：`7.5% × (1 - 0.11 × 3) = 5.025%`
- 费用假设已在 API 与前端显式展示
- 假设不等于该角色真实技能/声望/设施费用

未重复计算 SCC；只有 `upwell_structure` 场景才加入 SCC，本估值默认 NPC 空间站。

## 4. UNKNOWN 与状态

允许状态：

- `VALUED`
- `PARTIALLY_VALUED`
- `NO_MARKET_DATA`
- `INSUFFICIENT_DEPTH`
- `FEE_UNKNOWN`
- `LOCATION_UNKNOWN`
- `STALE_MARKET_DATA`
- `NOT_MARKETABLE`
- `VALUATION_ERROR`

规则：

- 任一缺失口径保持 `null`
- 未知不写 0
- 任务物品无订单：`NO_MARKET_DATA`
- 位置未知：`LOCATION_UNKNOWN`
- BPO/BPC 分类不互相覆盖
- 无法交易物品不计入可变现价值
