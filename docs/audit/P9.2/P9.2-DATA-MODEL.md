# P9.2 数据模型报告

## 1. 设计原则

- 当前资产集复用既有 `character_assets`，不另造一份“当前表”
- 历史快照不可覆盖
- 变化只存差异，不把观察变化写成购买/出售/损失
- Paper Trading 与真实资产完全分离
- 所有未知值保持 `NULL/UNKNOWN`，不写 0
- 本地标签只存 EVEAI 数据库，不写回 EVE

## 2. 复用实体

### `character_assets`

字段：

- `character_id`
- `item_id`
- `type_id`
- `location_id`
- `location_type`
- `location_flag`
- `quantity`
- `is_singleton`
- `is_blueprint_copy`
- `data_json`
- `synced_at`

主键：`(character_id, item_id)`

用途：最新完整同步后的当前集；仅在完整快照原子事务内替换。

## 3. 新增实体

### 3.1 `real_asset_sync_jobs`

记录每次同步：

- `job_id`
- `character_id`
- `trigger`：`manual/auto/api`
- `status`：`RUNNING/COMPLETED/FAILED`
- `phase`
- `pages_total/pages_fetched`
- `items_fetched/items_committed/items_skipped`
- `started_at/finished_at/duration_ms`
- `snapshot_id`
- `last_error`
- `source`

### 3.2 `real_asset_snapshots`

不可变快照头：

- `snapshot_id`
- `character_id`
- `job_id`
- `started_at/completed_at`
- `status`
- `total_items`
- `total_unique_types`
- `total_locations`
- `total_quantity`
- `data_hash`
- `source`
- `error_summary`
- `is_latest`

状态 CHECK：

- `RUNNING`
- `COMPLETED`
- `PARTIAL`
- `FAILED`
- `SUPERSEDED`

唯一约束：

```sql
CREATE UNIQUE INDEX idx_real_asset_snapshots_latest
ON real_asset_snapshots(character_id) WHERE is_latest = 1;
```

### 3.3 `real_asset_snapshot_items`

逐项快照：

- `snapshot_id`
- `item_id`
- `type_id`
- `quantity`
- `location_id/location_type/location_flag`
- `is_singleton/is_blueprint_copy`
- `parent_item_id`
- `raw_json`

主键：`(snapshot_id, item_id)`

### 3.4 `real_asset_locations`

位置解析缓存：

- `location_id`
- `location_type`
- `location_name`
- `solar_system_id/name`
- `region_id/name`
- `parent_location_id`
- `resolution_status`
- `resolution_source`
- `raw_json`
- `resolved_at`

`resolution_status`：

- `RESOLVED`
- `PARTIALLY_RESOLVED`
- `UNKNOWN`
- `ACCESS_RESTRICTED`

### 3.5 `real_asset_changes`

观察变化：

- `change_id`
- `character_id/item_id/type_id`
- `change_type`
- `prev_quantity/new_quantity`
- `prev_location_id/new_location_id`
- `source_class`
- `confidence`
- `from_snapshot_id/to_snapshot_id`
- `detected_at`

`change_type`：

- `ADDED`
- `QTY_INCREASED`
- `QTY_DECREASED`
- `MOVED`
- `REMOVED`
- `REAPPEARED`
- `CONTAINER_CHANGED`

`source_class`：

- `OBSERVED_CHANGE`
- `EVIDENCE_CORRELATED`
- `SOURCE_CONFIRMED`
- `SOURCE_UNKNOWN`

P9.2 默认只写 `OBSERVED_CHANGE`。

### 3.6 `real_asset_tags`

本地标签：

- `character_id`
- `item_id`
- `tag`
- `updated_at`

允许值：

- `SELF_USE`
- `FOR_SALE`
- `PRODUCTION`
- `MISSION`
- `SPARE`
- `TRADE_STOCK`
- `HOLD`

仅允许当前集物品打标签；不会发送到 ESI。

### 3.7 `real_asset_valuations`

估值运行头：

- `valuation_id`
- `character_id`
- `snapshot_id`
- `hub_location_id/hub_region_id`
- `market_snapshot_at`
- `fee_model_version`
- `status`
- `created_at/completed_at`
- `items_valued/items_unknown`
- `last_error`

### 3.8 `real_asset_valuation_items`

逐项估值：

- `valuation_id/item_id/type_id/quantity`
- `market_reference_value`
- `bid_liquidation_gross/net`
- `fillable_quantity/unfillable_quantity`
- `ask_replacement_gross/net`
- `statuses_json/flags_json`
- `price_source`

主键：`(valuation_id, item_id)`

### 3.9 `real_asset_opportunity_matches`

库存与机会联动：

- `match_id`
- `character_id/opportunity_id/type_id`
- `held_quantity`
- `accessible_quantity`
- `required_quantity`
- `support_class`
- `needs_transport`
- `locations_json`
- `snapshot_id`
- `computed_at`

唯一约束：`(character_id, opportunity_id)`

`support_class`：

- `SUPPORTED`
- `PARTIAL`
- `NEEDS_PURCHASE`
- `UNAVAILABLE`
- `UNKNOWN`

- `idx_real_asset_snapshots_latest`
- `idx_real_asset_snap_items_type`
- `idx_real_asset_snap_items_location`
- `idx_real_asset_changes_char_detected`
- `idx_real_asset_changes_item`
- `idx_real_asset_valuations_char_created`
- `idx_real_asset_val_items_type`
- `idx_real_asset_matches_char`

## 5. 数据隔离

- `real_asset_*` 不读取 `paper_*` 表
- 机会联动只读取 `p9_real_opportunities` 与 `character_assets`
- 估值只读取快照、SDE 与本地 `market_orders`
- AI/Agent 模块不参与估值和库存匹配确定性计算
- 未将市场估值写入钱包余额或 Paper 资金
