## 4. 数据库迁移

新增 9 张表：

1. `real_asset_sync_jobs`
2. `real_asset_snapshots`
3. `real_asset_snapshot_items`
4. `real_asset_locations`
5. `real_asset_changes`
6. `real_asset_tags`
7. `real_asset_valuations`
8. `real_asset_valuation_items`
9. `real_asset_opportunity_matches`

关键约束：

- 快照 `status` 只允许 `RUNNING/COMPLETED/PARTIAL/FAILED/SUPERSEDED`
- `real_asset_snapshots(character_id) WHERE is_latest=1` 部分唯一索引
- 变化类型、来源类别、置信度使用 CHECK 约束
- 标签使用 7 个本地枚举
- 估值状态与机会支持类别使用 CHECK 约束
- 所有迁移 `CREATE IF NOT EXISTS`，可重复执行

生产迁移前已备份并验证，见 `P9.2-PRODUCTION-VERIFICATION.md`。
