# P9.2 ESI 资产同步报告

## 1. 目标与边界

本模块只读取 EVE ESI 角色资产，建立本地不可覆盖快照。禁止：

- 真实资产写入
- 转移、合同、建筑操作
- 自动交易
- 用半份分页覆盖完整快照

## 2. 复用能力

- `src/eve/character-sync.ts`：既有 `syncAssets` 分页与 DELETE+INSERT 原子模式
- `src/eve/esi-client.ts`：`x-pages` 分页、TTL 缓存、重试、GET-only 网关
- `src/eve/sso.ts`：Token 自动刷新、角色归属校验
- `src/eve/capabilities.ts`：请求前能力快照
- Scope：`esi-assets.read_assets.v1`（已有，无新增）

## 3. 新同步管线

1. 创建 `real_asset_sync_jobs`（`RUNNING`）
2. `getEveCapabilities` 拍摄能力快照
3. `get_characters_character_id_assets` 获取全部分页
4. 逐行严格校验；任一行畸形则整批失败
5. 规范化 JSON 计算 sha256
6. 与最近 `COMPLETED` 快照比较
7. 单事务提交：
   - 替换 `character_assets`
   - 插入不可变快照与快照项
   - 写入位置解析缓存
   - 写入观察变化
   - 翻转 `is_latest`
   - 完成 job
8. 任一步失败回滚，保留旧完整快照并记录 `FAILED` job

## 8. 安全结论

- 全链路 ESI 仅 GET
- Token 只存数据库，不写日志、不写测试明文
- 失败 job 不覆盖旧数据
- 同一角色并发同步拒绝
- stale RUNNING job 超时回收
- 真实资产写入能力不存在
