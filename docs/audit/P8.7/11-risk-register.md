# P8.7 风险登记册

| 风险 | 等级 | 当前状态 | 缓解/限制 |
|---|---|---|---|
| 无真实 Paper 运行样本 | 高 | 未解决 | 所有策略 `INSUFFICIENT_SAMPLE`，禁止排名 |
| 快照报价可能在下单前消失 | 高 | 部分缓解 | 快照哈希、过期检查、逐档成交；仍无法证明订单仍存在 |
| 无真实订单队列 | 高 | 明确局限 | Mode B 要求 `visibleQueueAheadQty`，缺证据不成交 |
| 压力参数主观 | 中 | 明确局限 | Mode C 确定性、可复现，但不是概率分布 |
| 综合成本未知 | 中 | 未解决 | 资金占用、库存持有、未成交损失、风险折价保持 `UNKNOWN` |
| 做市/事件驱动链路不完整 | 高 | 未解决 | 不参与 validated 结论 |
| 前端仪表盘缺少浏览器端到端测试 | 低 | 未解决 | API 与组件已通过 typecheck/build，未做 Playwright |
| 真实数据库权益快照为空 | 中 | 未解决 | 新操作会写快照；历史账户首次操作后补序列 |
| 回测仅日频 | 中 | 明确局限 | 不宣称订单簿级回测 |

## 阻断条件

出现以下任一情况必须回到 `PAPER_TRADING_BLOCKED`：

- 账本差异
- fill 数量或费用不一致
- 未来数据泄漏
- 活跃过期机会继续成交
- ESI 只读边界失效
