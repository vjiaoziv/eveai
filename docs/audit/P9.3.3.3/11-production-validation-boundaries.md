# 11 生产验证边界

## 1. 验证等级定义

本报告严格区分：

- **已通过代码验证**：通过阅读当前源码、调用链和数据库定义确认；
- **已通过隔离测试数据验证**：使用临时 SQLite、stub ESI 和独立进程复现；
- **已通过真实环境验证**：使用真实生产部署、真实 ESI、真实账户与真实账本闭环验证；
- **尚未验证**：没有足够证据，不得推断成功。

本轮真实环境验证数量为：**0**。

## 2. 已通过代码验证

- ESI 操作目录和最终 HTTP 派发层仅允许 GET；
- 钱包同步主动建立能力快照并检查 `esi-wallet.read_character_wallet.v1`；
- 钱包同步路径参数、Token、证据、REAL 账本、失败队列和游标绑定固定角色；
- 钱包持久化前后及游标事务内复核身份和租约；
- 交易记录仍需人工核实后才能参与 FIFO；
- REAL/PAPER 数据库字段和约束保持隔离；
- Agent、LLM、Scheduler 不得修改 REAL 财务账本；
- UNKNOWN 不会被转换为 0；
- 资产响应先全量验证，再事务替换旧镜像；
- 非法钱包余额不会覆盖最后一次有效余额；
- FIFO 已实现盈亏只由已售库存成本确定性决定，未售 UNKNOWN 库存使库存成本/资金占用保持 N/A。

## 3. 已通过隔离测试数据验证

- 钱包能力快照缺失、过期和缺少 wallet scope；
- 用户切换活动角色时，请求仍绑定目标角色；
- 角色在 ESI 响应后或事务内失效时中止写入；
- 钱包分页超限、空页、畸形记录和游标失败重试；
- 低 transactionId 失败阻止高 ID 越过游标；
- 重复同步的交易、证据和关联幂等；
- FIFO known/unknown 成本组合、胜率和重算哈希稳定；
- 钱包异常余额保护；
- 资产分页畸形、后续页失败和事务回滚保护；
- 资产响应期间角色解绑反例：**失败，确认 F-P9333-04**；
- 钱包租约的跨连接及多进程基础场景；
- 资产双进程并发启动反例：**失败，确认 P1 缺陷**。
