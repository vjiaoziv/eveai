# EVE AI Agent 市场投资与交易决策技能指南 (eve-agent)

本项目为自建的 EVE Online 市场投资研究、套利扫描、风险管理与交易决策系统，采用真实多档位市场订单簿数据与严密经济学模型驱动。

## 核心原则与安全铁律
1. **严格只读原则**：系统绝不自动向 EVE 客户端或 ESI 发送任何买卖、改单、转账或资产变更指令。系统无任何游戏内写操作接口。
2. **人工执行闭环**：系统仅生成受管交易草案（`TR-YYYY-NNNNNN`），所有交易 100% 由飞行员本人在游戏客户端内手动确认并执行。支持实盘成交数据回传校验。
3. **确定性算术与风控**：所有税费、毛利、净利、ROI 均由确定性计算引擎 (`FeeEngine` / `OrderBookSimulator`) 逐档计算，严禁大模型主观臆断；强制执行 20% 现金储备底线、15% 单品累计持仓上限、30% 品类累计持仓上限与 5000 万防强杀货值门禁。
4. **反虚假价差（Phantom Spread）**：单笔提议数量严格以目标买单第一档（Top of Book）真实剩余量为上限，杜绝将低档位垃圾订单数量拼凑放大的严重误导。
5. **时差一票否决**：两地行情快照时间差超过 15 分钟时，系统自动判定为 D 级（高危陈旧数据），坚决予以风险否决，禁止生成执行草案。

## 命令行调用接口 (CLI)

在任何终端（PowerShell、CMD、bash、Hermes、dsh）中直接运行 `eve-agent`：

### 1. 基础数据与系统状态
```bash
eve-agent status                  # 查看守护服务状态与全域订单库统计 (155万条挂单)
eve-agent item "<物品名或ID>"     # 0毫秒极速查询物品分类、体积、质量与中英文名
eve-agent reprocess "<物品名>"    # 自动对比空间站解体产出矿物价值 vs 直接出售净利
eve-agent sde "<SELECT语句>"      # 直接执行本地 SDE 只读 SQL 查询
eve-agent ask "<投资咨询问题>"    # 向 AI 战术副官发起多轮投资与市场分析对话
```

### 2. 动态资金与全组合风险限额审计
```bash
eve-agent capital
```
- 读取角色钱包实时可用余额（当前：`68,318,340.97 ISK`）。
- **扣减锁定资金**：自动扣除 20% 现金储备底线（1,366 万 ISK）及在途已审批草案占用资金 (`inFlightCommittedIsk`)。
- **全局持仓限额**：输出单品 15% 累计持仓上限、品类 30% 累计持仓上限，以及 T1 工业舰单趟货运防强杀上限（5,000 万 ISK）。

### 3. 套利机会扫描与 10 阶段管线评估
```bash
# 跨贸易中心高安航运套利扫描 (0=Dodixie 15跳, 1=Hek 19跳, 2=Rens 25跳)
eve-agent scan-haul 0

# 站内套利扫描 (默认 Jita 4-4，买单吃进，卖单挂出，自动扣除双边税费)
eve-agent scan-station 60003760
```
- **深度穿透与滑点**：自动调用 `OrderBookSimulator` 计算逐档买入成本与逐档变现收入。
- **压力测试**：强制输出价格下跌 5%、10%、20% 以及顶档买单蒸发情景下的盈亏矩阵。
- **四级评级 (A/B/C/D)**：
  - **A 级**：时差 $\le 15$ 分钟，深度充足，净利率 $\ge 12\%$，抗跌 10% 仍盈利。
  - **B 级**：稳健型机会，净利率 $\ge 6\%$，抗跌 5% 仍盈利。
  - **C 级**：低流动性或抗跌脆弱，仅作控制台观察，禁止自动生成草案。
  - **D 级**：时差超限、深度错配、税后亏损或触发风控，直接一票否决。

### 4. 交易订单草案全生命周期管理
```bash
# 查看所有已生成的有效交易订单草案 (自动过滤已撤销草案)
eve-agent drafts

# 仅根据 A 级与经过验证的 B 级机会，自动生成最优订单草案 (TR-XXXXXX)
eve-agent draft-auto

# 飞行员审批通过某份草案 (审批后锁定在途资金，供游戏客户端手动执行)
eve-agent draft-approve <DRAFT_ID>

# 人工实盘执行反馈回传 (记录真实买卖价与税费，沉淀执行台账)
eve-agent record-trade --draft-id <DRAFT_ID> --buy-price <PRICE> --sell-price <PRICE> --qty <QTY> --fees <FEES>
```
*注：历史草案 `TR-2026-000001` 已被独立审计判定为虚假价差（杜迪克西 700k 买单仅剩 2 件，实盘亏损 -85.6%），已在数据库中永久变更为 `audit_revoked` 状态，系统硬性阻断其再次审批或执行。*
